# 과제 정의서: 소모품 재고 관리 프로그램

## 1. 과제 개요

- **과제명**: AI 활용 능력 테스트 – 소모품 재고 관리 프로그램 설계 및 개발
- **배경**: 현재 회사에서는 마우스, 키보드, USB 등 소모품의 재고를 엑셀로 관리하고 있다고 가정한다.
- **목표**: AI 도구(ChatGPT, Copilot 등)를 자유롭게 활용하여 소모품의 재고를 조회하고 수량을 변경할 수 있는 간단한 프로그램을 설계하고 개발한다.

## 2. 제약 및 자유도

| 구분 | 내용 |
|------|------|
| 개발 언어 | 자유 선택 |
| 개발 방식 | 자유 선택 |
| AI 도구 | 자유 활용 (ChatGPT, Copilot 등) |
| 제출물 | 프로그램 소스코드를 별도 첨부 |

## 3. 반드시 포함해야 할 기능

상세 내용은 [functional-requirements.md](functional-requirements.md)를 참고한다.

- 재고 조회: 소모품별 현재 재고수량 표시
- 재고 변경: 소모품의 입고 및 출고에 따른 재고수량 변경

## 4. 제출물

- 프로그램 소스코드 (별도 첨부)
