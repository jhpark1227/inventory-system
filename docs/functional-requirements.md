# 기능 요구사항: 소모품 재고 관리 프로그램

> 과제 전체 내용은 [assignment.md](assignment.md)를 참고한다.
> 확정된 세부 내용은 [functional-requirements-detail.md](functional-requirements-detail.md)를 참고한다.

## 1. 필수 기능

### FR-01. 재고 조회
- 소모품별 **현재 재고수량**을 화면에 표시한다.

### FR-02. 재고 변경
- 소모품의 **입고** 및 **출고**에 따라 재고수량을 변경한다.
  - 입고: 재고수량 증가
  - 출고: 재고수량 감소
- 변경 내용은 **저장 전까지 작업본에만 반영**된다.

### FR-03. 재고 저장
- 모든 수정을 마친 뒤 **저장 버튼**을 누르면 작업본의 변경 내용을 **서버 메모리의 저장본**으로 확정한다.
- 저장하지 않은 변경은 **되돌리기**로 취소할 수 있다.

### FR-04. 엑셀 파일 첨부
- 사용자가 재고가 담긴 **엑셀 파일(.xlsx)을 첨부**하면 그 내용을 서버 메모리로 불러와 재고 데이터로 사용한다.
- 서버에는 파일을 저장하지 않는다.

### FR-05. 엑셀 파일 다운로드
- 저장본을 반영한 **엑셀 파일(.xlsx)을 내려받을 수 있다.**
- 첨부한 원본 파일을 기반으로 수량만 갱신하므로 사용자가 만든 서식과 다른 열이 유지된다.
